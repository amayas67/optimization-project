What does “optimal” mean?

Each algorithm colors the graph and returns a number of colors. The optimal value is the minimum number of colors found across all algorithms on the same graph.

  • When Backtracking (exact) is present, it computes the true chromatic number χ — the optimal is then absolute (mathematically proven).
  • When Backtracking is absent, the optimal becomes the best heuristic solution — the minimum found by the 10 first algorithms. It is an approximation, not a proof.
  • ⚠ In that case, The first ten always reaches 100% optimality, because it is defined as “at least one of the 10 first algorithms found the minimum” — and the minimum is by definition found by at least one of them.
