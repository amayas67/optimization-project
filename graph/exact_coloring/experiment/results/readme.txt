# README — Utility Scripts for Graph Coloring JSON Data

This repository contains two Python scripts to manage and clean up JSON files generated by graph coloring experiments.

- **`no_redondance.py`** – removes redundant JSON files by keeping only one file per distinct adjacency matrix.
- **`delete_report.py`** – recursively deletes all `.html` and `.json` files inside the `results/` folder.

---

## Prerequisites

- Python 3.6 or later
- No external libraries are required (all scripts use only the standard library)

---

## 1. `no_redondance.py`

### Purpose
Scans a directory (or the current directory) for `.json` files, extracts the adjacency matrix from each, and keeps only the first occurrence of each unique matrix. All unique files are copied into a `unique/` subfolder inside the scanned directory.

### Usage
```bash
python no_redondance.py [directory]
