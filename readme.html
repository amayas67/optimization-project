Running experiments

Everything is driven from the Configuration section of main.py (lines ~570–635): seed, graph type, parameters and included algorithms.

1

Move into the experiment folder and run the script:

python main.py

Adding your own algorithm

        
Create your file in graph/exact_coloring/algo/ — for example my_algo.py — which receives the adjacency matrix and returns (colors, nb_colors):

        
algo/my_algo.py


def my_algo_coloring(adj):
    """
    adj : adjacency matrix (list[list[int]])
    Returns : (colors, nb_colors)
      colors    : list[int] — color of each vertex
      nb_colors : int       — number of colors used
    """
    n = len(adj)
    colors = [0] * n
    # ... your coloring logic ...
    return colors, max(colors) + 1

        
Then import it in main.py (imports section, line ~53) and add it to ALGORITHMS:

        
main.py


from my_algo import my_algo_coloring

        
main.py — ALGORITHMS


ALGORITHMS = [
    # ... existing algorithms ...
    ("my_algo", "My Algorithm", lambda g: my_algo_coloring(g)),
]

Results
What each run generates

    

    
After each run, main.py writes two files into results/:

    

      

        INTERACTIVE REPORT
        
results/HTML/<type>/000001.html

        
Comparison table, SVG colorings, optimal/best verdict.

      

      

        MACHINE-READY DATA
        
results/json/<type>/000001.json

        
Features, labels and adjacency matrix — ready for your analysis pipelines.

      

    

    
Files are numbered sequentially: 000001 → 000002 → …

Statistics · stats.py
Aggregating reports

    

    
The script recursively analyzes every .html file in a directory and generates stats.html — an optimal/best cross-table per algorithm.


    

      

        
1 · Place the script

        
Copy stats.py into the directory containing the HTML reports to analyze, or pass the path as an argument.

        
2 · Run the statistics

        
bash — option 1


# from the reports directory
cd graph/exact_coloring/experiment/results/HTML
python /path/to/stats.py

        
bash — option 2recommended


cd graph/exact_coloring/experiment
python stats.py results/HTML

      

      

        
3 · What stats.html produces

        

          
ColumnDescription

          
            
OptimalNumber of times the algorithm reached χ (optimal colors)

            
% optimalCorresponding percentage (with progress bar)

            
BestNumber of times the algorithm was the best (fewest colors, then shortest time)

            
% bestCorresponding percentage

            
Total colorsSum of colors used across all reports

            
Total time (ms)Sum of execution times across all reports

          
        

        
🖱In stats.html, click an algorithm row to display the files (run_id) where it was optimal and best — each file is clickable and opens the corresponding report.
